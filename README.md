# Solana Pulse Mobile 📱⚡

**Solana Pulse Mobile** is a mobile application built for the Solana Mobile Hackathon.

## 🚀 About The Project
Solana Pulse Mobile integrates Solana blockchain capabilities with Android mobile infrastructure to provide smooth Web3 user experiences on mobile devices.

## ✨ Key Features
- **Mobile Wallet Adapter (MWA)**: Connect seamlessly with Solana mobile wallets (Phantom, Solflare, etc.).
- **Social & Location Features**: Location-based check-ins and social interactions directly on-chain/in-app.
- **Rewards System**: Earn and track rewards on Solana.

## 🛠 Tech Stack
- **Language**: Kotlin
- **Platform**: Android SDK
- **Blockchain**: Solana Mobile Stack (SMS) / Mobile Wallet Adapter
- **Build System**: Gradle
